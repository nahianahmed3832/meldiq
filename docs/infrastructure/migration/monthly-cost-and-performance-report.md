# Measured costs and performance

AWS Cost Explorer reported USD 0.1485486209 in October unblended S3 costs across the authenticated account, including a negative unallocated amount. This is not a Meldiq-only bill. The Frankfurt rate lookup for the first S3 Standard storage tier returned USD 0.0245 per GiB-month. At the verified 2,247,139,033 bytes across migrated versions and disk files, the storage-only equivalent is approximately USD 0.0513 per month. It excludes growth, metadata, requests, transfer, logging and retained Singapore storage. Sources: [AWS S3 pricing](https://aws.amazon.com/s3/pricing/) and the private Price List/Cost Explorer receipts.

Cloudflare reported a Free Website zone and standard Workers usage model. OAuth did not permit listing account subscriptions. Estimate private reads as one Worker invocation, one backend authorization call and one signed S3 read per request or range. Private reads do not get shared-cache savings. Public fixture cache hits can avoid repeat origin reads. Direct uploads create S3 PUT/part/complete requests with no Worker body relay. Cross-region copies, both retained buckets, CloudWatch requests, backups and internet egress are separate costs. The two 60-second external checks measure latency from both monitor regions. They do not measure client playback latency. [Workers pricing](https://developers.cloudflare.com/workers/platform/pricing/)

An AWS 5xx origin alarm and whole-bucket S3 request metrics are active. Account budgets already include orbit-monthly-10usd at USD 10, with actual 80% and forecast 100% notifications, plus a USD 200 Meldiq monthly budget. The new CloudWatch alarm has no notification target. Actual monthly Frankfurt egress, Worker requests, paid subscription add-ons, incremental backup and monitoring totals require billing data after activation. No combined monthly figure or guaranteed saving is claimed.

The independent live checks are scheduled every minute from two regions. For a 30-day month they schedule 86,400 fresh origin range checks plus 86,400 public fixture checks. The account dashboard confirmed Workers Free, with 576 of 100,000 daily requests used when inspected. The two checks contribute about 5,760 Worker requests per day. At present volume the incremental Worker subscription is $0. Private downloads do not enter shared cache. The supplemental Windows compatibility path incurs a Singapore PUT plus cross-region copy for an older client's successful upload. Normal updated clients upload directly to Frankfurt.

Frankfurt Standard requests cost $0.0054 per 1,000 writes/lists and $0.00043 per 1,000 reads in the queried AWS price list. At 86,400 mandatory origin checks, the corresponding S3 GET charge is about $0.037/month, plus public fixture cache misses. For a model with 86,400 storage PUTs and 86,400 storage GETs, the request cost is about $0.50/month. With the measured Frankfurt footprint (about $0.051/month) that model totals about $0.55/month before egress, retained Singapore storage, logs, alarms, taxes and AWS monitoring. It is a scenario, not an invoice.

The recovery hold pauses Singapore noncurrent-version expiration. Retained Singapore bytes can therefore grow over time.
