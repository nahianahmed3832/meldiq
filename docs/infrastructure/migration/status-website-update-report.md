# Independent status website

The status site is the existing Sites Worker with independent D1 storage and regional AWS Lambda measurements. The provider confirmed status.meldiq.app and its SSL certificate active. The provider origin remains available independently of the application VPS. During the separate database maintenance the public API fell to 503 while the status site continued serving current measurements from Frankfurt and Singapore.

Two components and two 60-second probes were registered through the existing protected admin API. Frankfurt object storage measures a real signed noncached byte-range read against the private origin. Cloudflare media delivery checks the contents of the public monitoring fixture. Each has a five-minute stale threshold and requires two successes to recover. The descriptions identify the staged storage and the public fixture. A fresh public response showed both operational while the overall site showed a major outage. Neither component is a claim that authorized customer downloads have been cut over.

Existing API, authentication, messaging, WebSocket, database, background, file upload/download, media, calls, push, web, Android, payments, CDN and DNS components continue to use their existing probes and historical data. Incident, maintenance and operator functions remain in the independent service. This storage work created no production test incidents, fake history or speculative maintenance window. The existing provider's custom domain became active during this work. Cloudflare custom-domain setup for media did not change the status site's routing.

Status unit tests, monitor tests and TypeScript passed. The production origin and public status JSON were verified externally, including through the public custom-domain certificate. A local network path received an edge 403 on the status site; a second network path returned the public status and fresh measurements. Historical incident creation/resolution was not tested by writing fake incidents into production. The live status API is /api/public/status and the compact endpoint is /api/public/summary.
