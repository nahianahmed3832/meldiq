# Cloudflare media delivery

The active Meldiq zone reported Free Website. Worker account settings reported the standard usage model. Account subscription listing was denied, so paid Worker billing features and regional processing entitlements are unverified. The Worker uses an exact custom-domain route with workers.dev and preview URLs disabled. No EU-only processing or residency guarantee is asserted.

The legacy authenticated GET continues to accept proxy=1. The candidate backend issues a 60-second opaque AES-GCM ticket bound to an attachment ID. Only the API has the grant key. When the Worker presents its separate secret and the ticket, the API rechecks the original session, membership, publication state, expiration and quota. It returns a short-lived GET or HEAD SigV4 origin URL to the Worker. The Worker only follows the exact configured HTTPS origin and object path. It forwards selected range and conditional headers and streams the response. Private responses use private, no-store and CDN-Cache-Control: no-store. Private data never enters the shared Cache API. Direct upload URLs and multipart bodies continue to go to S3.

The live /healthz path requests a fresh range from a fixed private fixture and verifies its exact bytes. The only public immutable cache entry is /public/origin-v1.txt, a deliberate monitoring fixture. Its path ignores arbitrary object keys and query variations. All other unrecognized paths are denied. There is no published public-media catalog. A valid private ticket is a short-lived bearer capability. Copying it can permit use until expiration or revocation. Do not log tickets, authorization headers or signed origin URLs.

Local Worker tests exercised range, HEAD, invalid paths, denied authorization, substituted origins and cache policy. Live tests verified TLS, anonymous denial, public fixture delivery and a signed ranged read from Frankfurt. Positive live customer attachment delivery still depends on deploying the matching API and testing an isolated authorized user. Worker secrets use Wrangler's secret system. Keep the API grant key separate from the Worker identity.
