No permissions or subscription entitlements are served from Redis. Authentication and authorization execute before accessing any cached user data. There is no indefinite dual-write migration.

API 0.73.0 leaderboards are derived reads of existing points/calls plus current community membership/visibility checks. They introduce no separate durable dataset or cache authority. The final staging candidate preserves these routes.
