# Name style fonts (API 0.46.0 name styles)

`res/font/name_*.ttf` are the same Latin subsets Meldiq Web ships (meldiq-web `public/fonts/names`, from Fontsource
5.3.0), converted from WOFF2 to TrueType unchanged. All are under the SIL Open Font License 1.1 (`OFL-name-fonts.txt`).

| File | Family | Designer |
|---|---|---|
| name_pixel.ttf | Silkscreen 400 | Jason Kottke |
| name_arcade.ttf | Press Start 2P 400 | CodeMan38 |
| name_script.ttf | Pacifico 400 | Vernon Adams, Jacques Le Bailly, Botjo Nikoltchev, Ani Petrova |
| name_block.ttf | Bungee 400 | David Jonathan Ross |
| name_tech.ttf | Orbitron 700 | Matt McInerney |

Characters outside Latin fall back to the app's own font.
